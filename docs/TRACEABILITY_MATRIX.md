## 3. Application requirement and assumption mapping

PULSE timing reuse and GUARDIAN policy remain distinct. The controller is a provisional synthesizable demonstration; the tank, pump, and sensor models are verification assets. The application mappings below cover both the required scenarios and the explicitly assumed policy needed to make them deterministic.

| Application scenario / assumption | Production/model responsibility | Verification evidence |
| --- | --- | --- |
| Required normal LOW → MID → FULL operation; APP-01/02/03 thresholds and hysteresis | Sensor model derives `{full, above_low}`; controller starts only at qualified LOW, continues through MID, stops FULL. | P-025 / A; P-029 verifies reset at MID does not restart. |
| Required noise rejection; APP-01 independent Boolean inputs | Sensor model supports noise mask; PULSE qualifies each predicate independently. | P-026 / B1/B2; P-012…P-014 and P-019 independently exercise boundaries/concurrency. |
| Required absent-response protection; APP-04/08 initial response and source-dependent flow | Pump model distinguishes command from flow; timer measures window; controller latches suspected dry-run. | P-027 / C; exact N/PULSE and N+1/controller deadlines. |
| Required defined recovery; APP-05 manual clear with no automatic retry | Controller PROTECTED latch and `fault_clear`; restored source alone does not restart. | P-028 / D; P-029 / E reset recovery; P-031 / G disable clearing. |
| Required reset at different stages; APP-03/05 reset/qualification behavior | Common reset to PULSE/controller; model reset separately controlled by bench. | P-029 / E at startup, monitoring, filling, and fault. |
| APP-06 simultaneous response/timeout priority | Controller handles usable MID/FULL before timer done; PULSE cancellation priority unchanged. | P-030 / F for both MID and FULL, using raw stimulus scheduling without force; P-021 shared-edge preservation. |
| APP-07 unqualified/contradictory thresholds and operational disable | Controller inhibits startup or stops fill; PULSE enable clears validity; protection latch obeys clear/reset/disable. | P-031 / G plus P-029 startup/reset. Spontaneous internal validity corruption is not injected. |

All application cases above passed in both the workspace and fresh-clone regressions: 715 self-checks across 684 cycles, finishing at 13,671 ns. These results do not imply final team acceptance of APP assumptions.
